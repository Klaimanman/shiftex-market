# ShiftEX Market — איך זה עובד

כתובת האתר: **https://shiftex-market.pages.dev**

ShiftEX הוא לוח פרטי שבו הצוות מוסר, מחפש ומחליף משמרות. הוא **כלי תיאום בלבד** — הוא לא משנה את סידור העבודה הרשמי ולא מאשר העברות. את ההעברה עצמה מעדכנים מול רכז/ת השיבוץ.

---

## חלק א׳ — מדריך למנהל/ת (את/ה)

### צעדים ראשונים (פעם אחת)
1. נכנסים לאתר עם Google, ממלאים **טלפון נייד** ולוחצים **המשך**. מכאן נפתחת האפליקציה ויש לשונית **ניהול** (אייקון מגן).
2. **ניהול → משמרות**: מזינים שעת התחלה וסיום לבוקר, צהריים, לילה וכונן. (לילה למשל 23:00–07:00.) השעות קובעות מתי מודעה נסגרת אוטומטית.
3. **ניהול → הגדרות ארגון**: מזינים את המייל של רכז/ת השיבוץ.
4. **ניהול → תגים והסמכות**: בודקים שהמיפוי נכון ומתקנים לפי המציאות:
   | תג | נותן גישה לעמדות |
   |---|---|
   | סיור | סיור 50, סיור 51 |
   | מוסמך מסוף | מסוף |
   | מאבטח בכיר | סיור 53, אולם נוסעים |
   | — | קשמ״ז פתוחה לכולם |
5. **ניהול → תגים**: מוסיפים לעצמך את התגים שלך (במסך **עובדים** → לוחצים על השם שלך).
6. **ניהול → קודי הזמנה → קוד חדש**: מעתיקים את הקוד (הוא מוצג **פעם אחת בלבד**).
7. שולחים לצוות בקבוצה הפנימית: את כתובת האתר + הקוד.

### אישור עובדים
כל מי שנרשם מופיע ב-**ניהול → עובדים → ממתינים**. לוחצים על השם, בודקים שהתגים שבחר/ה נכונים (אפשר לתקן), ולוחצים **אישור הצטרפות**. רק אחרי האישור העובד/ת רואה את הלוח.

### פעולות ניהול נוספות
| מה | איפה |
|---|---|
| השעיה זמנית / ביטול גישה לצמיתות | עובדים → שם → השעיה / ביטול גישה (נכנס לתוקף מיד) |
| מינוי מנהל/ת נוסף/ת | עובדים → שם → מינוי למנהל |
| הסרת מודעה לא תקינה | ניהול → מודעות → הסרה (בעל המודעה מקבל הודעה) |
| הוספה או השבתה של עמדה | ניהול → עמדות |
| החלפת קוד הזמנה שדלף | ניהול → קודי הזמנה → ביטול, ואז קוד חדש |
| מי עשה מה | ניהול → יומן פעולות |

## חלק ב׳ — מדריך לעובדים (אפשר להעביר לצוות)

### הרשמה
1. נכנסים ל-**https://shiftex-market.pages.dev** → **כניסה עם Google**.
2. ממלאים שם וטלפון נייד (הטלפון לא מוצג לכולם — רק למי שפונה אליך על מודעה).
3. מזינים את **קוד ההזמנה** ובוחרים את **התגים** שלך (סיור / מוסמך מסוף / מאבטח בכיר).
4. מחכים לאישור ההנהלה.

### להתקין כאפליקציה בטלפון
- **אייפון**: Safari → כפתור השיתוף → **הוספה למסך הבית**.
- **אנדרואיד**: Chrome → ⋮ → **התקנת אפליקציה**.

### שלושה סוגי מודעות (כפתור ＋)
| סוג | מתי |
|---|---|
| **מסירה** | יש לי משמרת ואני רוצה שמישהו ייקח אותה |
| **חיפוש** | אני מחפש/ת משמרת נוספת (אפשר לבחור כמה תאריכים) |
| **החלפה** | אני נותן/ת משמרת שלי תמורת משמרת אחרת |

אפשר לסמן **אופציה ל־12 שעות**, לתת שם למשמרת שאינה רגילה (למשל "משמרת אירוע"), ולהוסיף הערות.

### הלוח השבועי
- רואים את השבוע הנוכחי (ראשון–שבת). לוחצים על יום כדי לראות את המודעות שלו, מחולקות לבוקר / צהריים / לילה / כונן.
- **סינון**: לפי סוג, משמרת, עמדה, אופציה, או "רק משמרות שאפשר לקחת".
- משמרת עם 🔒 דורשת תג שאין לך — רואים אותה, אבל אי אפשר לבקש אותה.
- המודעות מסודרות לפי סדר הפרסום — מי שפרסם ראשון מופיע ראשון.

### מצאתי משמרת — מה עכשיו?
1. נכנסים למודעה → **פנייה בוואטסאפ**. נפתחת הודעה מוכנה שאפשר לערוך, והיא נשלחת מהוואטסאפ שלך.
2. אפשר גם **הבעת עניין** — בעל/ת המודעה מקבל/ת התראה באפליקציה.
3. כשסוגרים ביניכם — **בעל/ת המודעה** לוחץ/ת **סגירת המודעה → המשמרת נלקחה**, ובוחר/ת מי לקח.
4. אחרי הסגירה מופיע כפתור **מייל לרכז השיבוץ** — נפתחת טיוטה מוכנה באפליקציית המייל, עם כל הפרטים. שולחים אותה משם.

> פנייה בוואטסאפ לא סוגרת את המודעה. רק בעל/ת המודעה סוגר/ת אותה.
> מודעה נסגרת אוטומטית כשהמשמרת מתחילה.

### מסירות, חיפושים והתראות
- **מסירות משמרת**: כל המשמרות שעמיתים מוסרים (כולל הצעות החלפה), לפי תאריך.
- **חיפושי משמרת**: מי מחפש משמרת ובאילו תאריכים — אם יש לך משמרת מתאימה, אפשר לפנות ישירות.
- **התראות** (הפעמון): כשעולה משמרת שמתאימה לך, כשמישהו מתעניין במודעה שלך, וכשהחשבון אושר.
- **חיפושים שמורים**: בלוח בוחרים סינון → **שמירת החיפוש** → מקבלים התראה כשעולה משמרת מתאימה.

### פרטיות
- רק עובדים מאושרים רואים את הלוח.
- מספר הטלפון לא מופיע ברשימות — רק כשמישהו פונה על מודעה פעילה.
- אפשר למחוק את החשבון בכל עת: **הגדרות → מחיקת החשבון**.
